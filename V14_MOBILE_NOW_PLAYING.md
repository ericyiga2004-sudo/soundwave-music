# SoundWave V14 — Mobile Now Playing

- Mobile Song Details is now an immersive Now Playing screen while keeping SoundWave colors/theme.
- Hides the duplicate app header, bottom tabs, and global mini-player visual on mobile only; the single hidden audio engine stays mounted.
- Adds a top down-arrow close control, share action, and top-edge swipe-down gesture to return to the previous page.
- Caps artwork size using viewport width and viewport height so low-resolution covers are not stretched too large.
- Uses compact responsive typography for small/short phones.
- Adds queue support to the shared music player context and exposes Add to Up Next from Song Details and recommendations.
- Reworks mobile transport: exact seek slider, previous song, -30 seconds, play/pause, +30 seconds, next song.
- Adds compact album and artist relationship cards below the Now Playing stage.
- Keeps lyrics collapsible and below the first playback view.
- Retains the existing desktop layout and SoundWave light/dark design tokens.
